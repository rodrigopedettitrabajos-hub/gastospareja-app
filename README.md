# Gastos Pareja - app instalable (Android)

Página de entrada para poder **Instalar aplicación** desde Chrome en Android.
Apps Script no deja servir manifest ni service worker, así que esta página (GitHub Pages)
los tiene y muestra adentro la web de Apps Script de siempre. No hay datos ni código de la app acá.

- `pruebas/` → web de pruebas
- raíz (`/`) → web de producción (la que se instala)
- `precios/bocata.tsv` → ofertas del mailing de Bocata (las lee Claude de las fotos del mailing; la sección Surtidos las trae con "Traer ofertas")

El código de la app está en el repo privado `webgastospareja`.
